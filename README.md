
## Mission
To return biological sovereignty to the individual through non-invasive, hardware-native wellness tracking. BiOracle V12 turns a standard smartphone into a real-time biometric observation laboratory.

## Core Intellectual Property: Claim 12
**Recursive Differential Triage:** A multi-step logic gate that utilizes real-time sensor data (Oculo-Vascular/Acoustic) to dynamically generate adaptive wellness insights and track physiological responses to lifestyle inputs.

## Technical Pillars

### 1. Identity Baseline
- **Method:** User-provided profile inputs
- **Hardware:** N/A (software logic)
- **Logic:** Age, gender, lifestyle, and self-reported health baselines to personalize wellness tracking.

### 2. Gastro-Acoustic Analysis
- **Method:** Digital stethoscopic monitoring
- **Hardware:** Smartphone microphone
- **Logic:** Tracks gut sounds (borborygmi) and motility patterns to identify digestive activity trends over time.

### 3. Oculo-Vascular Mapping
- **Method:** Remote Photoplethysmography (rPPG)
- **Hardware:** Front-facing camera
- **Logic:** Measures heart rate (HR), heart rate variability (HRV), and respiratory rate from facial skin color changes. Tracks coherence and autonomic balance.

### 4. Frequency-Based Remediation Tracking
- **Method:** Response logging
- **Hardware:** Haptic motor / speakers
- **Logic:** Allows users to log exposure to audio frequencies or haptic patterns and observe correlated changes in HRV and coherence over time.

## Tech Stack
- **Engine:** React Native / TypeScript
- **Hardware Hooks:** Camera (rPPG), Microphone (Acoustics), Haptics
- **Deployment:** Expo Go / GitHub
